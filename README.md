# 🏏 IPL Data Analysis (Exploratory Data Analysis)

## 📌 Project Overview
This project performs a comprehensive Exploratory Data Analysis (EDA) on the Indian Premier League (IPL) dataset using Python. The objective is to clean historical match and ball-by-ball records, evaluate key team and player performance metrics, and visualize tournament trends.

## 🛠️ Tools & Libraries Used
* **Python**
* **Pandas & NumPy** (Data Cleaning, Merging & KPI Calculations)
* **Matplotlib & Seaborn** (Data Visualization)
* **Jupyter Notebook**

## 📊 Key Analysis & Insights
1. **Franchise Dominance & Win Rate:** Mumbai Indians and Chennai Super Kings lead in total wins, while Gujarat Titans holds the highest overall win percentage (62.22%).
2. **Toss & Chasing Advantage:** Captains winning the toss predominantly choose to field first, resulting in a 50.59% match win rate for toss winners.
3. **Batting KPIs:** Virat Kohli, Shikhar Dhawan, and Rohit Sharma lead the all-time run charts, while power-hitters dominate strike rates (minimum 1,000 balls faced).
4. **Bowling Economy:** Spinners like Muttiah Muralitharan (6.70) and Sunil Narine (6.76) rank among the most economical bowlers in IPL history (minimum 1,000 balls bowled).
5. **Major Venues:** Mumbai (173 matches), Kolkata (93 matches), and Delhi (90 matches) have hosted the highest number of IPL games.

## 📂 Dataset
The dataset (`matches.csv` and `deliveries.csv`) contains match-level and ball-by-ball records across 17 IPL seasons, sourced from Kaggle.
